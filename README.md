# Generative AI Labs

Hands-on experiments and mini-projects exploring LLM applications,
agentic systems, retrieval, tool use, evaluation and Generative AI
engineering patterns.

## About

This repository contains practical experiments focused on building
applications and systems powered by Large Language Models.

The projects emphasize architecture, orchestration and AI system
behavior rather than specific frameworks.

## Repository Scope

- LLM Applications
- Prompt Engineering
- Structured Outputs
- Retrieval-Augmented Generation
- Agents
- Multi-Agent Systems
- Tool Use
- Memory
- Context Engineering
- LLM Evaluation
- Workflow Automation
